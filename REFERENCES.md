# References

## Design patterns

Erich Gamma, Richard Helm, Ralph Johnson, and John Vlissides. *Design Patterns: Elements of Reusable Object-Oriented Software*. Addison-Wesley, 1994. ISBN 978-0-201-63361-0. [Publisher's book page](https://www.informit.com/store/design-patterns-elements-of-reusable-object-oriented-9780201633610).

The book provides the Gang of Four pattern names and taxonomy that organize this repository. This is an independent educational project by Sanfor2004, with its own explanations, example programs, diagrams, and exercises. It does not reproduce the book's chapters, diagrams, or example code, and does not distribute a copy of the book.

## Modern C++

The [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines.html) provide guidance on resource management and interfaces. In particular, the resource-management section discusses RAII, ownership, and smart pointers. These principles inform the examples; a design pattern does not require heap allocation or inheritance in every implementation.

## Reading the examples

The examples intentionally isolate one design idea. Their output tests demonstrate particular behaviors, not production readiness. Read each article's limitations before adapting its code: exception handling, concurrency, ownership, and validation depend on the application.

ASCII diagrams and SVGs describe this repository's own classes and collaborations. They are simplified teaching diagrams rather than complete UML specifications.
