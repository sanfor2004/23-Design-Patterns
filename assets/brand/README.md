# Sanfor2004 brand assets

[Logo](logo.svg) · [Social preview](../social-preview.png) · [Editable preview](../social-preview.svg)

The logo was copied unchanged from the owner's portfolio project, `sanfor2004.github.io`, at `public/assets/brand/logo.svg`. Its portfolio brand guide explicitly identifies it as the Sanfor logo used on the home page and in navigation. The accompanying identity configuration identifies the account as Sanfor2004. The original SVG is 56 × 38; preserve that aspect ratio and its `#EE5712` strokes.

Only this designated brand mark was copied. The source portfolio and its assets were preserved. No third-party photographs, illustrations, icon libraries, or font files were imported.

The social preview is a 1280 × 640 composition for 23 Design Patterns. It uses the same SVG paths, warm paper background (`#e7c99f`), dark text (`#25170e`), orange accents, thin rules, and technical labels established by the portfolio brand guide. The SVG embeds the mark and has no external images or font dependencies; system font fallbacks are declared. The PNG is the ready-to-use export.

The logo is reproduced at its original proportions in the root READMEs and preview. The preview can be uploaded in the GitHub repository's social-preview settings; keeping the file here does not configure that setting automatically.
